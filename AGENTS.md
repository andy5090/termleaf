# Repository boundary

This repository is public. Keep terminal application, shared Rust core, language
assets, website and their tests here.

- Desktop and mobile development belongs in the private `andy5090/termleaf-apps`
  repository (local sibling `../termleaf-apps`).
- Server and subscription development belongs in the private
  `andy5090/termleaf-cloud` repository (local sibling `../termleaf-cloud`).
- Never register application credentials or development Variables in this public
  repository. Verify the destination repository is private before storing them.
- Use `localhost` for local URLs and OAuth callbacks.

Do not reintroduce app/server source here or rewrite existing public history as
part of ordinary development.
